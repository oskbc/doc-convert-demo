# 57. 見積内容

## 1. 見積もりの構成要素
見積もり提示額は、単なる作業時間の合計ではありません。以下の要素で構成されます。

$$見積金額 = (作業工数 \times 単価) + バッファ(リスク予備費) + 諸経費$$

## 2. 作業工数の算出方法（積み上げ法）
「ざっくり1ヶ月」ではなく、タスクを最小単位（WBS）まで分解して積み上げます。

| タスク分解 | 想定作業 | 工数(h) | 根拠 |
| :--- | :--- | :---: | :--- |
| **画面A実装** | レイアウト作成 | 2.0 | 類似画面Bの流用が可能 |
| | バリデーション実装 | 1.0 | 標準ライブラリ使用 |
| | API繋ぎ込み | 2.0 | I/F仕様書 v1.0 準拠 |
| | 単体テスト | 3.0 | 正常系・異常系計10ケース |
| **小計** | | **8.0** | |

## 3. バッファ（リスク予備費）の考え方
「何も起きなければこの時間で終わる」という理想値に対し、リスク係数を掛けます。
不安だからといって、理由なく倍にするのはNGです。

- **既知の技術・類似案件**: 係数 1.1 〜 1.2
- **新規技術・複雑な仕様**: 係数 1.3 〜 1.5

## 4. 前提条件の明示
見積もりは「前提条件」とセットでなければ成立しません。以下を必ず記載してください。

- **対象ブラウザ**: Chrome最新版のみ（IEは対象外）。
- **支給物**: デザインデータはXX日までにFigmaで受領すること。
- **データ移行**: 旧システムからのデータ抽出は顧客側で実施すること。

> **ポイント**
> 見積もりとは「金額の提示」ではなく**「お約束できる範囲の定義」**です。
