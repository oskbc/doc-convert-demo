# 58. 箇条書き

## 1. 箇条書きのメリット
長文（べた書き）は読み手にストレスを与えます。箇条書きを使うことで、以下の効果があります。
1.  **視認性**: 瞬時に全体像が掴める。
2.  **構造化**: 親子関係が明確になる。
3.  **論理性**: 漏れやダブりに気づきやすくなる。

## 2. 悪い例と良い例

### 悪い例（べた書き・階層混在）
> ログイン機能については、IDとパスワードを入力して認証を行いますが、その際にエラーがあれば赤字で表示し、パスワードを忘れた場合は再発行画面へ遷移できるようにする必要があり、またセキュリティのため5回失敗したらロックします。

### 良い例（構造化）
> **ログイン機能の要件**
> * **認証入力**
>     * IDおよびパスワードによる認証を行う。
> * **エラーハンドリング**
>     * 認証失敗時はエラーメッセージを赤字で表示する。
>     * 5回連続失敗時はアカウントをロックする。
> * **その他**
>     * 「パスワードを忘れた場合」のリンクを設置し、再発行画面へ遷移させる。

## 3. 作成のルール
### 3.1. 粒度を揃える（並列関係）
同じ階層には同じレベルの情報を置きます。「果物」の話をしている階層に「りんご」と「八百屋」を並べてはいけません。

### 3.2. 一文一義
一つの箇条書きには一つの要素だけを書きます。「AしてBしてCする」は分割します。

### 3.3. 文頭・文末を揃える
- 名詞止めなら全て名詞止めにする。
- 動詞（〜する）なら全て動詞にする。

### 3.4. MECE（漏れなくダブりなく）
リストアップする際は、全体を網羅しているか意識します。
（例：顧客層を分けるなら「男性・女性・その他」など）
