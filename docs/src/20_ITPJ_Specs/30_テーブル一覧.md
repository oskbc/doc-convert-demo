## 3. 共通カラム定義
全テーブル（または主要テーブル）に共通して付与するカラム。

| 論理名 | 物理名 | 型 | 説明 |
| :--- | :--- | :--- | :--- |
| 作成日時 | `created_at` | TIMESTAMP | レコード作成日時 (Default: NOW) |
| 作成者 | `created_by` | VARCHAR | 作成ユーザID |
| 更新日時 | `updated_at` | TIMESTAMP | 最終更新日時 |
| 更新者 | `updated_by` | VARCHAR | 最終更新ユーザID |
| 削除フラグ | `is_deleted` | BOOLEAN | 論理削除用 (Default: false) |
