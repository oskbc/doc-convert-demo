## 1. 凡例
- `||--o{` : 1対多
- PK: 主キー / FK: 外部キー

## 2. ER図

```mermaid
erDiagram
    m_users {
        int user_id PK
        string login_id
        string password_hash
        string name
        int role_type
    }

    m_customers {
        int customer_id PK
        string company_name
        string phone
        boolean is_active
    }

    m_products {
        int product_id PK
        string product_name
        int unit_price
    }

    t_orders {
        int order_id PK
        int customer_id FK
        int sales_rep_id FK
        date order_date
        int total_amount
        string status
    }

    t_order_details {
        int detail_id PK
        int order_id FK
        int product_id FK
        int quantity
        int price_at_order
    }

    m_users ||--o{ t_orders : "担当"
    m_customers ||--o{ t_orders : "発注"
    t_orders ||--|{ t_order_details : "明細"
    m_products ||--o{ t_order_details : "参照"
```

## 3. 特記事項
- 全テーブルに `deleted_at` を持つ論理削除方式  
- `created_by`, `updated_by` により操作ユーザーを保持
