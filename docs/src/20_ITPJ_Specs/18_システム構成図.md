## 1. システム構成図（全体）

```mermaid
graph TD
    subgraph Client ["クライアント環境"]
        PC["PCブラウザ"]
        SP["スマートフォン"]
    end

    subgraph Cloud ["AWS / Cloud Environment"]
        LB["Load Balancer"]

        subgraph WebLayer ["Web/APサーバー"]
            EC2_1["Web Server 01"]
            EC2_2["Web Server 02"]
        end

        subgraph DBLayer ["DBサーバー"]
            RDS_M[("Master DB")]
            RDS_S[("Slave DB")]
        end

        S3["S3 Storage"]
    end

    subgraph External ["外部システム"]
        Auth["認証基盤 (IdP)"]
        Mail["メール配信GW"]
    end

    PC -->|HTTPS| LB
    SP -->|HTTPS| LB
    LB --> WebLayer
    WebLayer --> DBLayer
    WebLayer --> S3
    WebLayer -.->|API| Auth
    WebLayer -.->|SMTP| Mail
```
