## 1. 全体構成概要
本システムは AWS (Amazon Web Services) 上に構築し、Web/AP分離構成およびマルチAZによる冗長化を採用する。

```mermaid
graph TB
    Internet((Internet))

    subgraph AWS Cloud [AWS Tokyo Region]
        ALB[Application Load Balancer]

        subgraph AZ_A [Availability Zone A]
            Web1[Web/AP Server 01]
            DB1[(RDS Primary)]
        end

        subgraph AZ_C [Availability Zone C]
            Web2[Web/AP Server 02]
            DB2[(RDS Standby)]
        end
        
        S3[S3 Bucket<br>(Assets/Logs)]
        SES[SES<br>(Mail)]
    end

    User[User Device] -->|HTTPS| Internet
    Internet --> ALB
    ALB --> Web1
    ALB --> Web2
    Web1 --> DB1
    Web2 --> DB1
    Web1 -.-> S3
    Web1 -.-> SES
    DB1 -.->|Replication| DB2
```

## 2\. インフラリソース一覧

### 2.1. コンピューティング・ネットワーク

| リソース名 | サービス | スペック/設定概要 | 備考 |
| :--- | :--- | :--- | :--- |
| **Load Balancer** | AWS ALB | Internet-facing | SSL終端 |
| **Web/AP Server** | AWS ECS (Fargate) | vCPU: 2, Mem: 4GB | オートスケール設定あり (Min:2, Max:10) |
| **Bastion** | AWS EC2 (t3.micro) | - | メンテナンス用踏み台 (SSM接続) |

### 2.2. データベース・ストレージ

| リソース名 | サービス | スペック/設定概要 | 備考 |
| :--- | :--- | :--- | :--- |
| **Database** | AWS RDS for PostgreSQL | db.t3.medium (Multi-AZ) | Ver 13.x |
| **Storage** | AWS S3 | Standard | 画像、ログ保存用 |

## 3\. ネットワーク・セキュリティ要件

  - **通信暗号化**: クライアント〜LB間は HTTPS (TLS 1.2以上) とする。
  - **閉域網**: データベースは Private Subnet に配置し、インターネットからの直接アクセスを遮断する。
  - **WAF**: AWS WAFを導入し、SQLインジェクション等の攻撃を防ぐ。
