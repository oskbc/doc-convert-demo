## 1. 画面階層図
Webアプリケーションのルーティング階層を定義する。

```mermaid
graph TD
    Login[SCR-001 ログイン] --> Top[SCR-002 ダッシュボード]
    
    subgraph Estimates [見積管理]
        Top --> ListEst[SCR-101 見積一覧]
        ListEst --> DetailEst[SCR-103 見積詳細]
        ListEst --> NewEst[SCR-102 見積登録]
        DetailEst --> EditEst[見積編集]
    end
    
    subgraph Orders [受注管理]
        Top --> ListOrd[SCR-110 受注一覧]
        ListOrd --> DetailOrd[SCR-111 受注詳細]
    end

    subgraph Stocks [在庫管理]
        Top --> ListStk[SCR-201 在庫照会]
    end

    subgraph Admin [管理機能]
        Top --> UserMgmt[SCR-901 ユーザ管理]
        Top --> MastMgmt[SCR-902 マスタ管理]
    end
```

## 2\. ナビゲーション設計

### 2.1. グローバルナビゲーション（ヘッダー/サイドバー）

常時表示され、以下のメニューへのショートカットを持つ。

1.  ダッシュボード
2.  見積管理
3.  受注管理
4.  在庫照会
5.  設定（管理者のみ表示）

### 2.2. パンくずリスト

階層の深い画面（詳細画面等）にはパンくずリストを表示し、上位階層へ戻れるようにする。

  - 例: TOP \> 見積管理 \> 見積詳細(No.12345)
