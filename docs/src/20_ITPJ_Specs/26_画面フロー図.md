## ケース: 新規受注登録プロセス

```mermaid
graph LR
    Start(("開始")) --> List["ORD-002: 受注一覧"]

    List -->|新規作成| Reg1["ORD-001: 基本情報"]
    Reg1 -->|次へ| Reg2["ORD-001: 明細入力"]
    Reg1 -->|キャンセル| List

    Reg2 -->|戻る| Reg1
    Reg2 -->|確認| Confirm["ORD-001: 入力確認モーダル"]

    Confirm -->|修正| Reg2
    Confirm -->|確定| Complete["ORD-001: 完了画面"]

    Complete -->|一覧へ| List
    Complete -->|続けて登録| Reg1
```

## 画面遷移ルール
- **途中離脱:** キャンセル時は確認ダイアログ表示  
- **タイムアウト:** セッション切れ時はログイン画面へ遷移し、再ログイン後に元画面へ復帰
