## 対象I/F: IF-API-02 新着情報取得

## 1. 基本情報
- Endpoint: `/api/v1/news`
- Method: GET
- 認証: Bearer Token

## 2. リクエストパラメータ

| 名称 | 必須 | 型 | 格納 | 説明 |
|:---|:---|:---|:---|:---|
| limit | 任意 | Integer | Query | 取得件数(デフォ10) |
| category | 任意 | String | Query | info / alert |

## 3. レスポンス

### 3.1 正常 (200)
```json
{
  "count": 2,
  "items": [
    { "id": 101, "title": "メンテナンス", "date": "2023-10-01", "category": "info" },
    { "id": 102, "title": "障害復旧", "date": "2023-10-02", "category": "alert" }
  ]
}
```

### 3.2 エラー

| HTTP | Code | Message | 原因 |
|:---|:---|:---|:---|
| 401 | E40100 | Unauthorized | Token無効/期限切れ |
| 500 | E50000 | Internal Error | サーバー障害 |
