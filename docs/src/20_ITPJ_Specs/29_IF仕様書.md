## 1. [IF-201] 決済実行API
### 1.1. 概要
- **用途**: 注文確定時にクレジットカード決済（オーソリ確保）を行う。
- **接続先URL**: `https://api.test.com/v1/charges` (Example)
- **Method**: `POST`

### 1.2. リクエスト仕様 (Request)
**Headers**
| Key | Value | 備考 |
| :--- | :--- | :--- |
| Authorization | Bearer {ApiKey} | 秘密鍵を設定 |
| Content-Type | application/json | |

**Body Parameters**
| 項目名 | 物理名 | 型 | 必須 | 説明 |
| :--- | :--- | :--- | :---: | :--- |
| 金額 | amount | Integer | ○ | 通貨の最小単位 (例: 円) |
| 通貨 | currency | String | ○ | `jpy` 固定 |
| ソース | source | String | ○ | フロントエンドで生成したToken ID |
| 説明 | description | String | - | 注文番号 (`ORD-xxxx`) を設定 |

### 1.3. レスポンス仕様 (Response)
**Success (200 OK)**
| 項目名 | 物理名 | 型 | 説明 |
| :--- | :--- | :--- | :--- |
| 決済ID | id | String | トランザクションID (ch_xxxx) |
| ステータス | status | String | `succeeded` 等 |
| 金額 | amount | Integer | 決済された金額 |

**Error (4xx, 5xx)**
| 項目名 | 物理名 | 型 | 説明 |
| :--- | :--- | :--- | :--- |
| エラー型 | type | String | `card_error`, `api_error` 等 |
| コード | code | String | エラー詳細コード |
| メッセージ | message | String | ユーザ表示用メッセージ |

### 1.4. サンプルデータ
```json
// Request
{
  "amount": 5000,
  "currency": "jpy",
  "source": "tok_visa",
  "description": "Order: ORD-20240101-001"
}

// Response (Success)
{
  "id": "ch_1I5...",
  "object": "charge",
  "amount": 5000,
  "status": "succeeded"
}
```

## 2. [IF-301] 売上データ連携ファイル

### 2.1. ファイル仕様

  - **ファイル名**: `SALES_YYYYMMDD.csv`
  - **文字コード**: `Shift_JIS`
  - **改行コード**: `CRLF`
  - **区切り文字**: カンマ (`,`)

### 2.2. レイアウト定義

| No | 項目名 | 型/桁 | 必須 | 備考 |
| :--- | :--- | :--- | :---: | :--- |
| 1 | データ区分 | Char(1) | ○ | `1`:売上, `2`:返品 |
| 2 | 売上日 | Date(8) | ○ | YYYYMMDD |
| 3 | 店舗コード | Char(5) | ○ | |
| 4 | 伝票番号 | Char(12)| ○ | |
| 5 | 金額 | Num(9) | ○ | 税抜 |
