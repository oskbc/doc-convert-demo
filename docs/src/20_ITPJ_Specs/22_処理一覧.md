## 1. 凡例
- **種別:** バッチ / API / Worker(非同期)
- **難易度:** 高 / 中 / 低

## 2. 処理リスト

| ID | 処理名称 | 種別 | 起動トリガー/頻度 | 入力 | 出力 | 概要・目的 |
|:---|:---|:---|:---|:---|:---|:---|
| BAT-001 | 夜間データ同期 | バッチ | 日次 (02:00) | 基幹CSV | DB更新 | 基幹システムから出力された在庫CSVを取り込む |
| BAT-002 | 請求金額計算 | バッチ | 月次 (月末 23:00) | 売上テーブル | 請求テーブル | 月間売上を集計し請求額を確定 |
| API-101 | 住所検索API | API | フロント要求 | 郵便番号 | 住所情報 | 外部API利用の住所検索 |
| WRK-001 | メール送信 | Worker | キュー検知 | 送信キュー | メール | キューを監視し非同期でメール送信 |

## 3. 依存関係・制約事項
- **BAT-002** は **BAT-001** 完了後に実行すること。
- **API-101** は外部サービス利用のためレート制限（100req/sec）に注意。
