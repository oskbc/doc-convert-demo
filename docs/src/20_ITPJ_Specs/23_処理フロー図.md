## 対象処理: BAT-001 夜間データ同期

## 1. 処理概要
基幹システムからSFTP連携されたCSVを読み込み、商品マスタ・在庫テーブルを更新する。

## 2. 詳細フロー

```mermaid
flowchart TD
    Start(("処理開始")) --> A["設定ファイル読込"]
    A --> B["SFTPサーバー接続"]

    B --> C{"接続成功?"}
    C -- No --> E1["エラーログ出力<br>(接続エラー)"]
    E1 --> EndError(("異常終了"))

    C -- Yes --> D["CSVファイル有無確認"]
    D --> F{"ファイルあり?"}
    F -- No --> E2["警告ログ出力<br>(ファイルなし)"]
    E2 --> EndNormal(("正常終了"))

    F -- Yes --> G["CSVダウンロード"]
    G --> H["トランザクション開始"]

    H --> I["1行読み込み"]
    I --> J{"データチェック"}

    J -- NG --> K["エラーリストに追加"]
    J -- OK --> L["DB更新(Upsert)"]

    L --> M{"全行終了?"}
    M -- No --> I
    M -- Yes --> N{"エラーリストあり?"}

    N -- Yes --> O["ロールバック"]
    O --> E3["エラーログ出力<br>(データ不備)"]
    E3 --> EndError

    N -- No --> P["コミット"]
    P --> Q["バックアップフォルダへ移動"]
    Q --> EndNormal
```

## 3. エラー処理仕様
- **接続エラー:** 3回リトライし失敗時はシステム管理者へ緊急メール。
- **データ不備:** 1件でも不正があれば全件取り込まず中止（All or Nothing）。
