### 2.1. [BAT-002] 売上データCSV出力
日次で売上データを抽出し、基幹システムへSFTP転送する処理。

```mermaid
flowchart TD
    Start((開始))
    LogStart[開始ログ出力]
    
    %% データ抽出フェーズ
    SelectDB["当日の売上データ抽出<br>WHERE sales_date = Today"]
    CheckCount{データ件数 > 0?}
    
    %% 0件の場合
    CheckCount -- No --> LogSkip[スキップログ出力]
    LogSkip --> End((終了))

    %% データがある場合
    CheckCount -- Yes --> FormatCSV["CSVフォーマット変換<br>(文字コード: Shift-JIS)"]
    CreateFile[一時ファイル作成]
    
    %% 転送フェーズ
    ConnectSFTP[基幹サーバへSFTP接続]
    PutFile[ファイルアップロード]
    CheckTrans{転送成功?}
    
    %% エラーハンドリング
    CheckTrans -- No --> AlertMail[管理者へアラートメール送信]
    AlertMail --> ErrorEnd((異常終了))
    
    %% 成功時
    CheckTrans -- Yes --> UpdateStatus[連携フラグ更新: 済]
    DeleteTemp[一時ファイル削除]
    LogEnd[終了ログ出力]
    
    UpdateStatus --> End
    DeleteTemp --> LogEnd
    LogEnd --> End
```

### 2.2. [API-101] 見積金額計算ロジック

消費税（標準/軽減）と割引計算を含むロジック。

```mermaid
flowchart TD
    Start([リクエスト受信])
    Init[合計金額 = 0]
    
    subgraph Loop [明細行ループ]
        CheckTax{税区分判定}
        CheckTax -- 10% --> Calc10[単価 * 数量 * 1.1]
        CheckTax -- 8% --> Calc8[単価 * 数量 * 1.08]
        AddTotal[合計金額に加算]
    end
    
    Start --> Init
    Init --> Loop
    Loop --> CheckDisc{全体割引適用?}
    
    CheckDisc -- Yes --> ApplyDisc[合計金額 - 割引額]
    CheckDisc -- No --> Round["端数処理<br>(切り捨て)"]
    
    ApplyDisc --> Round
    Round --> Return([レスポンス返却])
```
