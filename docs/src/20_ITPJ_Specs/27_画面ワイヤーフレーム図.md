## 2. 画面別詳細レイアウト

### 2.1. [SCR-101] 見積一覧画面
**画面概要**: 作成済みの見積データを検索・一覧表示する。

#### 【レイアウトイメージ】
```text
+-------------------------------------------------------+
| [ヘッダー]                                            |
+-------+-----------------------------------------------+
| [Menu]| 検索条件エリア                                |
|       | [顧客名___] [期間___]～[___]  [検索ボタン]    |
|       |                                               |
|       | + [新規作成ボタン]                            |
|       |                                               |
|       | 一覧エリア                                    |
|       | | No | 顧客名 | 金額 | ステータス | 操作 |  |
|       | |----|--------|------|------------|------|  |
|       | | 1  | A社    | 100万| 承認済     | [詳細]|  |
|       | | ...                                      |  |
|       |                                               |
|       | [ページネーション < 1 2 3 > ]                 |
+-------+-----------------------------------------------+
```

#### 【UI要素定義】

| No | 項目名 | タイプ | 必須 | 編集 | 初期値 | 備考/アクション |
| :--- | :--- | :--- | :---: | :---: | :--- | :--- |
| 1 | 顧客名 | Text Box | - | ○ | 空 | 部分一致検索 |
| 2 | 期間(From) | Date Picker | - | ○ | 当月1日 | |
| 3 | 検索ボタン | Button | - | - | - | 検索実行 (API-101) |
| 4 | 新規作成 | Button | - | - | - | SCR-102へ遷移 |
| 5 | 一覧グリッド | Table | - | - | - | 20件/ページ表示 |
| 6 | 詳細リンク | Link | - | - | - | SCR-103へ遷移(ID引継) |
