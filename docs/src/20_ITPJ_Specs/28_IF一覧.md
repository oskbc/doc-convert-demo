## 1. 概要
本システムが提供、または利用するインターフェースの一覧。
- **IF区分**: `API` (Web API), `FILE` (ファイル連携), `MAIL` (メール)
- **方向**: `IN` (受信/Download), `OUT` (送信/Upload)

## 3. 共通仕様概要
- **文字コード**: 原則 `UTF-8` とする。ただし基幹連携ファイルは `Shift_JIS` とする。
- **タイムアウト**: 同期API呼び出しは `30秒` でタイムアウトとする。
- **リトライ**: ネットワークエラー時は `3回` までリトライを行う。
