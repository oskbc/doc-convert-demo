## 1. 本書の目的・分掌
本ドキュメントは、プロジェクトにおけるタスクの分解（WBS）、スケジュール、および担当者を定義し、進捗状況を可視化・管理することを目的とする。

- **管理対象**: プロジェクト計画書に基づいた全工程および詳細タスク
- **更新頻度**: 週次定例（または日次朝会）にて更新
- **担当者定義**: 各タスクの担当者は [33_体制図](../20_ITPJ_Specs/33_体制図.md) に定義されたロールまたは個人名に準拠する。
- **関連資料**: 
    - 仕様策定段階での機能別スケジュールや概算WBSについては [32_簡易WBS_ガントチャート](../20_ITPJ_Specs/32_簡易WBS_ガントチャート.md) を参照のこと。
    - 本書のスケジュールは No.32 の内容をベースに、リソースやプロジェクト制約を加味して詳細化したものである。

## 3\. タスク定義・予実管理一覧（WBS）

### 3.1. ステータス定義

| ステータス | 定義 | 備考 |
| :--- | :--- | :--- |
| **未着手** | まだ作業を開始していない状態 | |
| **処理中** | 作業中（WIP）の状態 | 進捗率10%〜90% |
| **レビュー中**| 作業が完了し、承認者の確認待ち | |
| **完了** | 承認が完了し、タスクがクローズした状態 | 進捗率100% |
| **保留** | 何らかの理由で作業を停止している状態 | 課題管理表とリンクさせること |
