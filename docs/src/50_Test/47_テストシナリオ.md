## 1. 本書の目的・分掌
本ドキュメントは、各テスト工程（UT/IT/ST等）における具体的な確認手順、入力データ、および期待される結果（合格基準）を定義する。

- **役割**: テスト実行者の操作指示書、およびテスト実施結果のエビデンス記録台帳として機能する。
- **記載粒度**: 操作手順は、システムを知らない第三者が読んでも迷わず実行できるレベルで記述する。
- **結果記録**: Github等で管理する場合、本ファイルの「結果」カラムを直接更新するか、別途Issue/Ticketと紐づけて管理する。

## 2. 凡例・共通パラメータ
### 2.1. ステータス定義
| ステータス | 意味 |
| :--- | :--- |
| **未実施** | まだテストを行っていない。 |
| **OK** | テスト実施し、期待値通りの結果となった。 |
| **NG** | 期待値と異なる結果（バグ）となった。 |
| **保留** | 環境要因や仕様未決により実施不可。 |
| **対象外** | 今回のテストサイクルでは実施しない。 |

### 2.2. テストパラメータ表（共通）
複数のテストケースで使い回す入力パターンの定義。

**【P01: ユーザ権限パターン】**
| パターンID | 権限ロール | 期待される挙動 | 備考 |
| :--- | :--- | :--- | :--- |
| P01-A | 管理者 (Admin) | 全機能利用可能 | |
| P01-B | 一般 (User) | 参照・登録のみ、削除不可 | |
